# 09 — Roadmap e Entregas

O roadmap detalhado — etapas, épicos, critérios de saída, caminho crítico e riscos — está em **[ROADMAP.md](../ROADMAP.md)** na raiz do repositório.
O caminho de desenvolvimento de cada área técnica está em **[docs/desenvolvimento/](desenvolvimento/README.md)**.

## Resumo das etapas

| Etapa | Sprints | Objetivo |
|-------|---------|----------|
| 0 — Fundação | S1–S4 | Monorepo, segurança do legado, recuperar o projeto Unity, simulador econômico, protótipo WebGL |
| 1 — Vertical Slice | S5–S8 | Login → célula 3D → turno de trabalho → coleta de THALER pelo servidor |
| 2 — Alpha fechado | S9–S14 | Região A1 completa na testnet: Lucky Box, profissões, imóveis, impostos, multiplayer |
| 3 — Beta + Mainnet | S15–S22 | Pets, fazenda, veículos, marketplace, GameVault, auditoria, teste de carga |
| 4 — Lançamento | S23–S26 | Mainnet, TGE do SCITY, venda de lotes da A1, espaços Spatial |
| 5 — Live Ops | S27+ | Anel A2, indústrias, mineração, energia, staking, marcas reais |
