# ADR-0003 — BNB Smart Chain como rede

- **Status:** Proposto
- **Data:** 2026-10-18
- **Trilhas afetadas:** contracts · backend · client

## Contexto
O nome do projeto, os materiais de marca e o público P2E apontam para a BNB Smart Chain (docs/11 §3).

## Opções consideradas
1. BNB Smart Chain.
2. Polygon PoS.
3. Base (L2).

## Decisão
BNB Smart Chain; BSC Testnet em dev e staging.

## Consequências
Contratos compatíveis com EVM, fáceis de migrar se necessário. Taxas baixas para mint de imóveis.
