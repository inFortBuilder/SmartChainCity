# infra

Infraestrutura como código (AWS), Docker Compose de desenvolvimento e runbooks.

```
infra/
├─ docker/      ← docker-compose.dev.yml
├─ terraform/   ← ou cdk/, conforme ADR
└─ runbooks/    ← incidentes, deploy, rotação de chaves
```
