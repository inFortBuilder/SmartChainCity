API REST em PHP e SDK cliente

O SCC Builder tem uma API REST em PHP e um SDK orientado a objetos (sdk/SccBuilder.php) para automatizar conversões direto nas suas aplicações PHP.

Testar o envio na API PHP (/api/convert.php)
Exemplo de integração com o SDK PHP
require_once 'sdk/SccBuilder.php';

use SccBuilder\SccBuilderClient;

$client = new SccBuilderClient('http://localhost/scc-builder/api');
$result = $client->convertFile('path/to/project.fbx', 'glb', true);

echo "Converted GLB URL: " . $result['output_url'];
Como exportar do software de arquitetura

3ds Max → GLB

Exporte o projeto como FBX (.fbx) ou OBJ (.obj) com "Embed Media" marcado, ou instale o plugin oficial Babylon.js / glTF Exporter para exportar .glb direto.

Revit → GLB

Vá em File → Export → CAD Formats → FBX. O SCC Builder transforma o FBX em um GLB leve, pronto para game. IFC não é lido: exporte FBX em vez dele.

SketchUp → GLB

File → Export → 3D Model → escolha Collada (.dae) ou OBJ (.obj). Marque "Export Texture Maps".

Lumion → GLB

O Lumion não exporta geometria: exporte o modelo de origem como FBX (.fbx) ou DAE (.dae) antes de importar no SCC Builder.
